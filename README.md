# Scraper-Automatizado-de-Perfiles-de-Instagram
Este proyecto consiste en un sistema automatizado de extracción de datos (Web Scraping) diseñado para recopilar información estructurada de perfiles de Instagram, incluyendo biografías, métricas de seguidores, publicaciones y contenido multimedia.   Desarrollado como proyecto práctico para la asignatura de Arquitectura de Software.
